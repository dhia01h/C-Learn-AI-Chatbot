#  C-Language Learning Chatbot  

##  Overview  
An **AI-powered educational chatbot** designed to help students **learn and practice the C programming language**.  
It explains concepts, corrects code, generates exercises, and supports interactive learning with **voice, OCR, and quizzes**.  

The project is built with **Chainlit + RAG** and enhanced with **speech recognition, text-to-speech, OCR, and Stack Overflow search**.  

---

##  Features  

### C Programming Focus  
- Generate C code snippets  
- Debug and correct C code  
- Provide simplified explanations for beginners  

###  Voice Interaction  
- **Speech-to-Text (STT)** → Ask questions by voice  
- **Text-to-Speech (TTS)** → Hear chatbot answers  

### OCR Integration  
- Import handwritten/printed code images  
- Automatic recognition and correction  

### Learning Tools  
- Auto-generated quizzes  
- Simplified mode for beginners  
- Multilingual explanations  

### Extra Tools  
- Stack Overflow search for errors  
- Session saving & history tracking  
- File attachments support  
- Choose your preferred **Language Model (LLM)**
